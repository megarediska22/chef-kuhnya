# Шеф кухня

Русскоязычный демонстрационный магазин замороженных домашних блюд. В пилотном меню 12 порционных блюд и четыре набора. Масса и цены предварительные. При оформлении магазин показывает пример итоговой корзины. Персональные данные, платежи и реальные заказы не обрабатываются.

[Открыть магазин](https://megarediska22.github.io/chef-kuhnya/) · [Каталог](https://megarediska22.github.io/chef-kuhnya/#/catalog)

## Локальный запуск

Требуются Node.js 24 и npm. Из корня репозитория выполните:

```sh
npm ci
npm run dev
```

Vite напечатает локальный адрес. Для проверки production-сборки:

```sh
npm run lint
npm test
npm run build
npm run preview
```

Команда `npm run typecheck` отдельно проверяет TypeScript. Браузерные тесты запускаются по адресу работающего сайта. Им нужны Python с пакетом Playwright и установленный Chrome. Аргументы и настройка дополнительного аудита axe описаны в `tests/browser_checks.py`.

## Устройство магазина

- `src/data/catalog.ts` содержит публичный ассортимент, массу, ориентировочные цены и комплектацию наборов.
- `src/components/Shop.tsx` отображает каталог, карточку, корзину и демонстрационное оформление. `src/cart.ts` сохраняет в localStorage только артикулы и количества.
- `src/main.tsx` обрабатывает маршруты после символа `#`. `src/Home.tsx` и `src/Information.tsx` содержат главную, информацию о доставке, бренде и сотрудничестве.
- `public/media/` содержит созданные для проекта иллюстрации подачи. Для сайта использованы AVIF и WebP, для карточки ссылки — JPEG. Внешних фотосервисов и шрифтовых CDN во время работы сайта нет.
- Шрифты Lora и Manrope распространяются по SIL Open Font License. Тексты лицензий находятся в `public/licenses/`.
- `.github/workflows/pages.yml` устанавливает зависимости, запускает проверки и публикует содержимое `dist/` в GitHub Pages.

Технологии — React, TypeScript, Vite и CSS. Все операции магазина выполняются в браузере. Новые опции доставки, продуктовые этикетки и фактическую доступность предстоит подтвердить перед открытием продаж.
